Capabilities

Everything a knowledge base needs

A complete ingestion-to-answer pipeline, engineered for reliability.

Document ingestion

Upload PDFs, Markdown, and text. Files are validated, queued, and processed asynchronously — the API responds immediately with a 202.

Semantic search

Text is chunked, embedded, and stored as vectors in MongoDB. Questions match meaning, not just keywords.

Grounded answers

An LLM answers using retrieved chunks as context — with source citations, and an honest "I don't know" when nothing matches.

Workspace isolation

Every document belongs to a workspace. Authentication, authorization, and tenant boundaries are enforced on every request.

Background processing

Extraction, chunking, and embedding run out-of-band with observable status: pending → processing → ready, or failed with diagnostics.

Production hardening

Rate limiting, retries with backoff, timeouts, usage tracking, structured logging, and Docker — failure never crashes the API.

Pipeline
